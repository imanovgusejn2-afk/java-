# Практическая работа (Git, JS, Google Sheets)

## Отчет об использовании ИИ

**Инструмент ИИ:** ChatGPT (или Claude)
**Промпт:** "Напиши JavaScript код для загрузки данных из Google Таблицы в формате CSV с помощью fetch() и выведи их в HTML-таблицу. Добавь обработку ошибок."

**Что ИИ сделал правильно:**
ИИ отлично сгенерировал базовую структуру функции `fetch()` и правильно использовал `async/await` для асинхронной загрузки данных.

**Что пришлось исправлять вручную (см. комментарии в script.js):**
1. **Отсутствие try/catch:** Изначально ИИ не предусмотрел обработку ошибок. Я добавил конструкцию `try...catch`, чтобы сайт не ломался, если интернет пропадет или ссылка будет неверной.
2. **Проблема с парсингом CSV:** ИИ предложил использовать библиотеку PapaParse. Я убрал её, так как для 3-5 строк это избыточно, и написал простой разбор через `.split()`.
3. **Символы переноса строки (\\r):** Код ИИ не очищал данные, из-за чего в ячейках таблицы появлялись невидимые символы. Я добавил `.trim()`.

**Чему я научился:**
Я понял, как публиковать Google Таблицы в CSV и как использовать `fetch()` для получения данных из внешних источников. Также я убедился, что код от ИИ нужно всегда проверять и дорабатывать напильником, особенно в части обработки ошибок.
